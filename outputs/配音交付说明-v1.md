## 三、manifest.json（软件读取用）

- 位置：`assets\audio\manifest.json`（生成过程中逐块更新）
- 每条字段：`id / file / voice / lang / chars / duration_sec / digest / seed`（seed 仅重采样条目有）
- `digest` 支持增量：同 id + 同文本 + 同参数 → 跳过；改了文案 → 只重生成改动条

## 四、追加 / 修改一条解说词（引擎现成能力）

**单条**（示例）：

```bat
D:\NarrationEngine\run.cmd --voice A "新文案……" -o D:\tmp\solar-system-cpp\assets\audio\evo.xxx_pro.mp3
```

**批量**：写 `tasks.json` 后：

```bat
D:\NarrationEngine\run.cmd --batch tasks.json --out-dir D:\tmp\solar-system-cpp\assets\audio
```

任务字段：`id / text / voice（A 男 · B 女）/ lang（zh）/ speed / seed / out`。
（`speed=0.9` 放慢一成、`0.8` 放慢两成；`seed` 一般不用，问题条重采样用。）

## 五、质量备注

1. **数字读法**：中文 TTS 对数字串按字符读（`5778`→「五七七八」、`2018`→「二零一八」），属正常惯例；如需「五千七百七十八」式读法需改文案本身。
2. **语速**：当前全量按原速（1.0×）。如需整体更从容，引擎支持整套 `speed=0.8/0.9` 重生成；对比试听在 `_试听\evo.mid.s0_pro_sp0.9.mp3`。
3. **已知需人工听感复核**：`mas.s0_pro` 的数字/缩写读法（ASR 疑似「35000→三五零零零」「CNO→吸烟头」）——如听感不佳，可改文案写法或换 seed 重生成。
4. **重采样与可复现**：同文案 + 同参数（含 seed）→ 输出**逐字节可复现**；问题条换种子即可得到新 take。
5. `narration.json` 的 `_voice` 字段为产品对外文案口径（「原创 TTS 音色」），与生成所用 A/B 音色不冲突；如口径需调整请另行说明。
