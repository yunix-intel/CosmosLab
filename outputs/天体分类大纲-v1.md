# 天体分类与演化体系大纲 v1（对标本科教材精度）

> 对标：Carroll & Ostlie《现代天体物理》、Ryden《宇宙学导论》、Planck 2018 参数。
> 目标：教科书般精准，普通人能看懂。数值一律给出来源与适用条件，不确定处明确标注。
> 本大纲确认后，再按章节逐批补数据结构、演化链与解说词。

## 0. 总纲：分类的三个正交轴

1. **尺度轴**：恒星 → 恒星系统 → 星际介质 → 星团 → 星系 → 星系团/超团 → 宇宙网 → 可观测宇宙
2. **演化轴**：恒星一生（质量决定命运）、星系演化、宇宙热历史
3. **能源轴**：核聚变 / 引力坍缩 / 吸积释放 / 宇宙学膨胀

任何天体都可定位到三轴交叉点。App 内三个尺度层级（太阳系 / 银河系 / 宇宙）只覆盖尺度轴的一部分，本大纲补齐其余两轴。

## 第一编 恒星（Stars）

### 1.1 光谱分类（Morgan–Keenan 双维）

- **温度型**：O–B–A–F–G–K–M（附 L / T / Y 褐矮星延续）
  - 每型给出有效温度范围、主导谱线（如 H Balmer 在 A 型最强、B 型 He I、M 型 TiO 分子带）
  - 必须讲清：光谱型是**温度序列**，不是质量或年龄序列
- **光度级**：I（超巨星）/ II / III（巨星）/ IV（亚巨星）/ V（主序矮星）/ VI（亚矮星）/ VII（白矮星，偶用）
- **赫罗图**：主序带、巨星支、水平支、渐近巨星支、白矮星序列；不稳定带（instability strip，造父变星带）

### 1.2 质量阈值（决定命运的分水岭，太阳金属丰度下）

| 阈值 | 物理含义 |
|---|---|
| 0.013 M☉ | 氘聚变下限（行星 / 褐矮星分界，IAU 定义） |
| 0.075 M☉ | 氢聚变下限（褐矮星 / 红矮星分界） |
| ~0.5 M☉ | He 点火方式分界：以下 He 白矮星（宇宙年龄内到不了）；以上经 He 闪或平稳点火 |
| ~2.0–2.3 M☉ | He 核是否简并（He 闪 vs 平稳 He 燃烧，依金属丰度与对流超射而移） |
| ~8 M☉ | 碳点火下限：以下 CO 白矮星 / ONe 白矮星；以上走完 Ne–O–Si 燃烧 |
| ~8–10 M☉ | 电子俘获超新星区间（ONeMg 核坍缩，超新星分类中的特殊通道） |
| ~20–25 M☉ | 黑洞 / 中子星分界（强依赖金属丰度、质量损失、自转；只给区间，不给单值） |
| 1.44 M☉ | 钱德拉塞卡极限（非自转 CO 白矮星） |
| ~2.0–2.3 M☉ | TOV 上限（中子星最大质量，依物态方程；给区间 + 最新大质量脉冲星证认） |

### 1.3 三条演化主链

- **低质量链**（M ≲ 0.5 M☉）：主序（极长寿命）→ He 白矮星（理论终点；宇宙年龄不够，尚未实测单星演化产物）
- **中等质量链**（~0.5–8 M☉）：主序 → 红巨星支（H 壳层燃烧）→ He 闪/平稳 He 燃 → 水平支 → AGB（热脉冲、质量损失、星风）→ 行星状星云 + CO/ONe 白矮星
- **大质量链**（≳ 8 M☉）：主序（O/B）→ 超巨星（红/蓝，含沃尔夫–拉叶阶段 WC/WN/WO）→ 核坍缩（II 型 / Ib / Ic 型超新星，光谱判据：H 线有无、He 线有无）→ 中子星 / 黑洞
- 每条链给出：**时标量级**（如太阳主序 ~10¹⁰ yr、大质量星全寿命 ~10⁶–10⁷ yr）、**核心产物**、**抛回星际介质的元素**

### 1.4 恒星残骸

- 白矮星**：DA / DB / DC 等光谱型；质量–半径反比关系；冷却序列与年龄测定；Ia 型超新星前身星（单简并 / 双简并，钱德拉塞卡 / 次钱德拉塞卡爆发）
- **中子星**：脉冲星（灯塔模型、自转供能 / 吸积供能）、磁星（SGR / AXP）、毫秒脉冲星（再加速）；质量–半径与物态方程
- **恒星级黑洞**：X 射线双星判据（质量函数 > 3 M☉ 无光学对应体）、引力波并合（LIGO–Virgo–KAGRA 事件类型）

### 1.5 变星与双星（演化会改写单星命运）

- 脉动变星：造父变星（周光关系，距离阶梯第一级）、RR Lyrae、天琴 RR 与星族 II、米拉变星
- 激变变星与 X 射线双星：洛希瓣、吸积盘、新星 vs 超新星（新星是表面热核失控，白矮星存活）
- 双星演化通道：包层共有、Ia 前身星、双中子星并合（GW170817 + 千新星 AT2017gfo：r 过程元素起源证据）

## 第二编 星际介质与星云（ISM & Nebulae）

- **气体相**：冷中性（CNM）、暖中性/电离（WNM/WIM）、热电离（HIM）、分子云（恒星形成场所）
- **尘埃**：消光曲线、2175 Å 隆起（bump）、红化与测距改正（与超新星宇宙学的消光改正衔接）
- **发射星云**（H II 区，如 M42）、**反射星云**、**暗星云**（Barnard 天体）、**行星状星云**（AGB 抛射物 + 中心白矮星电离）、**超新星遗迹**（蟹状星云 M1：1054 年客星；Cas A；Vela）
- **恒星形成**：Jeans 判据量级、金斯质量公式适用条件、原恒星分类（Class 0/I/II/III）、初始质量函数（Salpeter 斜率 Γ = −1.35 及其适用范围）

## 第三编 星团（Star Clusters）

- **疏散星团**（如昴星团 M45、毕星团）：年轻、银盘、色–星等图定年龄
- **球状星团**（如 M13、M80）：年老（~110–130 亿年）、晕族、第二参数问题；**球状星团年龄 = 宇宙年龄下限**（与 Planck 13.8 Gyr 自洽性检查）
- **星协**（OB 星协，成协膨胀定年龄）

## 第四编 星系（Galaxies）

### 4.1 形态分类（Hubble–de Vaucouleurs 序列）

- E（椭圆，E0–E7，椭率定义）、S0（透镜）、S / SB（旋涡，Sa–Sd，核球–盘比序列）、Irr（不规则 I / II）
- **必须讲清**：音叉图是形态序列，**不是演化序列**
- 矮星系：dE / dSph / dIrr / UCD / LSB；**星系质量–金属丰度关系**

### 4.2 结构与动力学

- 旋涡星系：核球 / 盘（指数盘）/ 晕 / 棒 / 旋臂（密度波 vs 随机自传播，讲清争议）；**旋转曲线平坦 → 暗物质晕**（Rubin 1970s，王星 M33 / NGC 3198 等经典曲线）
- 椭圆星系：de Vaucouleurs r¹/⁴ 律 / Sérsic 轮廓、Fundamental Plane（Re–σ–Ie）
- 定标关系：Tully–Fisher（旋涡）、Faber–Jackson / Dₙ–σ（椭圆）——**次级距离指标**，衔接哈勃图面板

### 4.3 星系演化纲要

- 颜色–星等双峰（蓝云 / 红序列 / 绿谷）、恒星形成主序（SFR–M*）、淬灭（quenching）机制候选：AGN 反馈、冲压剥离、 strangulation、形态淬灭（讲清哪些是证认、哪些是假说）
- 并合序列（Toomre 序列）、高红移星系命名（LBG / LAE / SMG / DRG，一句话定义 + 选择效应警告）

## 第五编 活动星系与超大质量黑洞（AGN & SMBH）

- **统一模型**：黑洞 + 吸积盘 + 宽线区 / 窄线区 + 尘埃环 + 喷流；**视角决定分类**（Type 1 / Type 2、射电噪 / 射电静）
- 类别：Seyfert（I/II）、类星体（QSO/QSR）、蝎虎座 BL Lac / FSRQ（blazar）、射电星系（FRI/FRII，Fanaroff–Riley 形态–功率分界）
- **必须含**：M87（EHT 2019 第一张黑洞阴影；喷流 5000 ly）、Sgr A*（EHT 2022；恒星轨道 Ghez/Genzel 诺奖工作）、3C 273（第一颗认出的类星体，z = 0.158）
- 标度关系：M–σ、Magorrian 关系；AGN 反馈与星系–黑洞共同演化（讲清相关性 ≠ 因果链已证全）

## 第六编 大尺度结构与暗物质（LSS & Dark Matter）

- 星系群 / 团（Virgo 已有；补 Coma、Bullet 1E 0657−558）、超团（Laniakea 已有）、纤维 / 片 / 空洞（Boötes 已有；补 Sloan Great Wall 已有、CfA2 长城）
- **暗物质证据链（按强度排序）**：星系旋转曲线 → 星系团位力质量 / X 射线气体静力平衡 → Bullet 星系团的 lensing–X-ray 分离 → CMB 第 3 峰高度（Ωc h²）→ 大尺度结构功率谱
- **直接说什么没找到**：直接探测（XENON/LZ）迄今零结果；只给上限，不给发现宣称
- 引力透镜：强透镜（Einstein 环）、弱透镜（cosmic shear，宇宙学探针之一）

## 第七编 宇宙学（Cosmology）

- **热历史时间轴**（与"大爆炸动态演化模拟"一一对应）：
  - 普朗克时期（量子引力未知，明确标"理论空白"）
  - 暴胀（假说地位：解决视界/平坦/单极问题；原初引力波 B 模**未探测到**）
  - 电弱 / QCD 相变（~10⁻¹² s / ~10⁻⁵ s，温度量级）
  - BBN（~1 s–3 min：⁴He ~25% 质量分数、D/H 定重子密度 Ωb h² —— 与 CMB 独立一致）
  - 复合 / 退耦（38 万年，z ≈ 1090，CMB 2.7255 K）
  - 黑暗时代 → 第一代恒星（Pop III，理论预言为主）→ 再电离（z ~ 6–10，Gunn–Peterson  trough）
  - 结构形成 → 加速膨胀（1998 SNe；Δχ² 由本项目哈勃图面板实测给出）
- **ΛCDM 参数**（Planck 2018）：H₀ = 67.4、Ωm = 0.315、Ωb h²、Ωc h²、τ、ns、As；**H₀ tension**（Planck vs SH0ES ~5σ，讲清这是当前最大未解之一）
- **距离阶梯**：视差 → 造父（Leavitt）→ TRGB / SBF → SNe Ia → 哈勃流（每级给出适用范围与系统误差来源）
- **命运**：Big Freeze（ΛCDM 默认）/ Big Rip（w < −1，未证认）/ Big Crunch（需闭合宇宙，已被 CMB 排除为平直）——讲清条件句

## 第八编 高能暂现源与多信使（Transients & Multi-messenger）

- 超新星分类（光谱判据优先：II / IIb / Ib / Ic / Ia；能量来源：核坍缩 vs 热核）
- GRB（长/短， collapsar vs 并合；余辉标准模型一句话 + 例外警告）

- 引力波源分类：BBH / BNS / NSBH（GW150914 / GW170817）；**标准汽笛**（H₀ 独立测量路线之一）
- 中微子天文：SN 1987A（已在 LMC 条目）、IceCube-170922A（TXS 0506+056）
